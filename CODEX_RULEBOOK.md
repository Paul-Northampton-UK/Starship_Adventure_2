# Codex Rules for Starship Adventure

## Patch Style
- Make ONE patch per request.
- No huge diffs. Keep changes small and focused.
- Do NOT rewrite, refactor, or delete big sections unless explicitly told.

## Safety
- Always keep UTF-8 for all file reads.
- Do NOT invent new systems or move files unless instructed.

## NLP Work
- Keep intent mapping simple and explicit.
- Single-letter shortcuts handled before full-word logic.
- Never return None for target unless input is empty.

## Behaviour
- No creative guesses.
- Follow instructions exactly as written.
- If uncertain, ask for clarification.
